# ICSC Conference Website

This repository is the source for the GitHub Pages site at `icsc-conf.github.io`.

The site is now built from source files by GitHub Actions. Do not edit generated
HTML or CSS files directly.

## Source Structure

```text
src/
  site/
    pages/
      root-landing-page.tsx          source for /
      past-conferences-page.tsx      source for /past-conferences.html
      2026/
        conference-page.tsx          source for /2026/index.html
        call-paper-page.tsx          source for /2026/call.html
        committee-page.tsx           source for /2026/oc.html
        sponsors-page.tsx            source for /2026/sponsors.html
    components.tsx                   shared layout, header, footer, paths
    content.ts                       shared conference text, dates, links, lists
  styles/
    site.css                         Tailwind input CSS

assets/
  2026/                              2026 static files and downloads

past_conferences/
  2016/ ... 2025/                    editable legacy conference archives

scripts/
  build-pages.tsx                    static page generator
  dev-server.ts                      local development server
```

## Which File To Edit

| Public page or content | Edit this source file |
| --- | --- |
| Home page `/` | `src/site/pages/root-landing-page.tsx` |
| Home page text, dates, links, focus areas | `src/site/content.ts` |
| Past conferences page `/past-conferences.html` | `src/site/pages/past-conferences-page.tsx` |
| Past conference list and links | `src/site/content.ts` |
| 2026 main page `/2026/index.html` | `src/site/pages/2026/conference-page.tsx` |
| 2026 call for papers `/2026/call.html` | `src/site/pages/2026/call-paper-page.tsx` |
| 2026 committee `/2026/oc.html` | `src/site/pages/2026/committee-page.tsx` |
| 2026 sponsors `/2026/sponsors.html` | `src/site/pages/2026/sponsors-page.tsx` |
| Shared header, footer, buttons, page shell | `src/site/components.tsx` |
| Site-wide generated CSS | `src/styles/site.css` |
| 2026 flyers, media pack, promotional email | `assets/2026/` |
| Legacy 2016-2025 archive pages | `past_conferences/YYYY/` |
| Build output paths | `scripts/build-pages.tsx` |

## Do Not Edit These Generated Files

These files are generated by the build and are not tracked as source:

```text
index.html
site.css
about.html
past-conferences.html
2026/*.html
2026/assets/
2026/ICSC_flyers.zip
```

If you need to change one of those pages, edit the matching file under `src/`.

## Local Development

Install dependencies:

```bash
pnpm install
```

Run the local development server:

```bash
pnpm run dev
```

Generate the site into the repository root for local preview:

```bash
pnpm run build
```

Generate pages into a separate output directory, matching CI behavior:

```bash
SITE_OUTPUT_DIR=_site pnpm run build:pages
```

## Deployment

GitHub Actions builds the published site into `_site` and deploys that artifact
to GitHub Pages.

The deployment workflow:

1. Copies editable legacy archives from `past_conferences/YYYY/`.
2. Copies 2026 assets from `assets/2026/`.
3. Generates `index.html`, `site.css`, `past-conferences.html`, and
   `2026/*.html` from `src/`.
4. Publishes `_site` to GitHub Pages.

For backward compatibility, CI also publishes legacy URLs such as
`/2019/index.html` and `/2026/assets/...`, even though their source files now
live under `past_conferences/` and `assets/2026/`.

## Pull Request Guard

The `Guard generated files` workflow rejects PRs that edit generated files or
old source locations directly. Edit the source files listed above instead.
